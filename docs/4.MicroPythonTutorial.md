# Tutorial de MicroPython

Este es un tutorial de MicroPython.

## 1. Introducción

MicroPython es una implementación concisa y eficiente del lenguaje de programación Python 3, que incluye un pequeño subconjunto de la biblioteca estándar de Python y está optimizado para ejecutarse en microcontroladores y entornos restringidos.

### Características

*   **Compatible con Python 3**: Soporta la mayoría de la sintaxis de Python 3.
*   **Ligero**: Diseñado específicamente para dispositivos con recursos limitados.
*   **Interactivo**: Soporta REPL (Read-Eval-Print Loop).

## 2. Preparación del hardware

Necesitarás una placa de desarrollo que soporte MicroPython, como ESP32 o ESP8266.

```python
# 这是一个 Python 代码示例
import machine
import time

pin = machine.Pin(2, machine.Pin.OUT) # Inicializa GPIO2 como salida

while True:
    pin.value(not pin.value()) # Invierte el estado del pin
    time.sleep(1) # Retraso de 1 segundo

# Este es un comentario, debería ser traducido
```
