### ロボットカーを組み立てる

組み立てる前に、アクリル板の保護フィルムを剥がしてください。

![](./media/image-20250421084803390.png)

1. 車輪を車のベースに取り付ける

![](./media/image-20250421084822843.png)

車輪の突き出た端をモーターシャフトに結合する

![](./media/image-20250421084843786.png)

![](./media/image-20250421084858441.png)

![](./media/image-20250421084918504.png)

2. アクリル板とバッテリーケースを取り付ける

![](./media/image-20250421084935331.png)

![](./media/image-20250421084950731.png)

![](./media/image-20250421085000236.png)

![](./media/image-20250421085011761.png)

![](./media/image-20250421085022933.png)

![](./media/image-20250421085033137.png)

![](./media/image-20250421085050675.png)

注：次の取り付けに進む前に、まず図に示すようにバッテリーボックスの電源線を接続してください。

![](./media/1.jpg)

![](./media/image-20250421085102511.png)

![](./media/image-20250421085111815.png)

3. ユニバーサルホイールを取り付ける

![](./media/image-20250421085132655.png)

![](./media/image-20250421085143743.png)

![](./media/image-20250421085159753.png)

4. 超音波モジュールとmicro:bitを取り付ける

![](./media/image-20250421085218115.png)

![](./media/image-20250421085231507.png)

Micro:bitのLEDマトリックスは前方を向く

![](./media/image-20250421085249494.png)

**ロボットプロジェクトを開始する前の注意事項：**

1. micro:bitとロボット間の接触不良を避けるため、Microbitが車体のMicrobitインターフェースに正しく挿入されていることを確認してください。コネクタはMicrobitの丸い穴の端を覆う必要があります。

micro:bitのLEDマトリックスは前方を向いています。

![](./media/image-20250421085619362.png)

2. 単4電池をバッテリーケースに入れ、ケースを車体ベースのVCCコネクタに接続します。

![](./media/image-20250421085647541.png)

3. バッテリーからの電源を制御するスライドスイッチをオフにします。

![](./media/image-20250421085708011.png)
