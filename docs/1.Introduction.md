# Introduction

![](./media/KS4036F.png)

La mini-voiture robot Keyestudio est une voiture multifonctionnelle basée sur le BBC micro:bit. Elle est équipée d'une multitude de capteurs et de périphériques pour vous aider à comprendre comment utiliser le micro:bit et en apprendre davantage sur l'électronique.

De plus, elle dispose de nombreux connecteurs universels pour trous de blocs de construction pour une connexion facile à d'autres périphériques, vous pouvez utiliser votre expérience et votre imagination pour créer des inventions plus intéressantes.

## Paramètres

**Note :** les deux phares colorés, les deux capteurs photosensibles, le récepteur IR et les deux moteurs sont déjà intégrés dans la plaque de base de la voiture.

![](./media/KS4036F35.png)

Entrée du port de connexion : DC 4.5V

Tension de fonctionnement des capteurs : 3V

Vitesse du moteur : 200 tr/min

Plage de température de fonctionnement : 0-50℃

Dimension : `99*78*58` mm

Attributs de protection de l'environnement : ROHS

La vitesse du moteur peut être ajustée via le PWM

En raison du petit nombre de ports IO du micro:bit, la carte micro:bit envoie des instructions de contrôle au STC8G1K08 via l'IIC, puis le ST8G1K08 envoie le PWM pour contrôler le moteur HR8833 afin de piloter l'IC, contrôlant ainsi la rotation du moteur. Le LED RGB est contrôlé de la même manière que ci-dessus.
