# はじめに

![](./media/KS4036F.png)

Keyestudio Mini Robot Carは、BBC micro:bitをベースにした多機能カーです。豊富なセンサーと周辺機器を搭載しており、micro:bitの使い方を理解し、電子機器についてさらに学ぶのに役立ちます。

さらに、他の周辺機器との接続を容易にするために、ビルディングブロックの穴のユニバーサルジャックが多数残されており、あなたの経験と想像力を使って、より興味深い発明を作成することができます。

## パラメータ

**注:** 2つのカラーヘッドライト、2つの感光センサー、IRレシーバー、2つのモーターはすでに車のベースプレートに統合されています。

![](./media/KS4036F35.png)

コネクタポート入力: DC 4.5V

センサーの動作電圧: 3V

モーター速度: 200RPM

動作温度範囲: 0-50℃

寸法:`99*78*58` mm

環境保護属性: ROHS

モーター速度はPWMで調整可能

micro:bitのIOポート数が少ないため、micro:bitボードはIICを介してSTC8G1K08に制御命令を送信し、その後ST8G1K08はHR8833モーター駆動ICを制御するためにPWMを送信し、モーターの回転を制御します。LED RGBも上記と同じ方法で制御されます。
